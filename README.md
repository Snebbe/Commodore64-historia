# 🕹️ Commodore 64 – När Barnen Mötte "Boten" (1983–1984)

En interaktiv retro-webbsida och historisk essä om **Commodore 64**, lanseringen i Sverige via Handic Electronic AB 1983, det stora prisraset i julhandeln, och hur de tidiga 80-talsbotarna sådde fröet till dagens artificiella intelligens.

## ✨ Funktioner
- **Autentisk CRT-upplevelse:** Scanlines, fosforglöd, bildrörskrökning och flimmer som kan styras i realtid.
- **Färglägen:** C64 Klassisk Blå, Grön Fosfor (P1), Bärnsten Fosfor (P3) och Cyberpunk 1984.
- **SID 6581 Ljudmotor:** Inbyggd 8-bitars synthesizer via Web Audio API med ljudeffekter och chiptune-arpeggio.
- **Interaktivt Prisreglage:** Se prissänkningen från våren 1983 (5 995 kr) till julhandeln 1983 (3 995 kr) och motsvarande penningvärde idag.
- **Animerad Försäljningsräknare:** Jämför Sveriges 100 000 sålda datorer mot de 2,4 miljoner som såldes globalt 1984.
- **Minispel ("C64 Tactical Duel"):** Spela Luffarschack / 3-i-rad mot antingen:
  - *1983 VIC-64 Dummy Bot* (gör 80-talsmisstag och kastar ur sig syntaxfel)
  - *2026 Super-AI Model* (minimax oslagbar algoritm med AI-kommentarer)
- **Dilemma-Simulator:** Välj mellan att cykla till kompisen eller sitta uppe hela natten med boten.
- **C64 BASIC Terminal:** En interaktiv kommandotolk för att köra retrokommandon som `HELP`, `LIST`, `RUN`, `POKE 53280,X`, `PRINT`, `BEEP`, `STATS` m.fl.
